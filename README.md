# WeightSort
Программа на языке java для решения данной задачи: Василий и Петр пошли заниматься в фитнес зал "Бухгалтерия". Каждый месяц фитнес-зал вывешивает список всех посетителей с их весом отсортированный по возрастанию. Петр каждый раз очень расстраивается из-за того что он всегда внизу списка с наибольшим весом. У Василия все хорошо и поскольку он лучший друг Петра решил, что немного подправит функцию сортировки и таблица будет сортироваться не по весу, а по сумме чисел данного веса (189 -> 18). Помогите Василию решить эту задачу. Пр. "56 65 74 100 99 68 86 180 90" отсортированный список должен начать выглядеть вот так: "100 180 90 56 65 74 68 86 99".

Запуск через "cmd" командой - java WeightSort.
Для проверки кода вводим через пробел данные числа - 56 65 74 100 99 68 86 180 90.
Отсортированный список должен выглядеть так "100 180 90 56 65 74 68 86 99".
Если всё получилось - код работает исправно.
